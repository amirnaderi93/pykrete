machine.

## What you're seeing

Every keystroke (debounced ~300 ms) runs the source through pykrete's
single-file analyzer. Diagnostics show up as squiggles in the editor
and as one-liners in the panel below — the same format
`pykrete check` prints in your terminal.

The wasm playground is single-file only: no cross-file resolution, no
project config, no `.pyk-import` declarations. Everything you can do
locally with `pykrete check path/to/file.pyk` works here; multi-file
projects need the CLI.

## Limits

- **No share-via-URL yet.** Refresh discards your edits. Bookmarkable
  snippet URLs are on the roadmap.
- **Desktop-first.** Monaco editor is hard to use on a phone; the
  diagnostics list is still useful on small screens, but typing is
  not.
- **Single-file analysis only.** Multi-file imports, project
  configuration, and the `.pyk-import` mechanism need real file
  system access — use the CLI for those.

## Want it locally?

```bash
pip install pykrete
pykrete check path/to/your/file.pyk
```

The [Install](/pykrete/getting-started/install/) page walks through
the full editor setup (LSP for autocomplete and hover, the VS Code
extension, project configuration).
